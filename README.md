A tortoise that refuses to be slow: red helmet, aviator goggles, tiny cape, and a rocket flame strapped to its shell, blasting off through a golden portal ring at sunset while confetti rains down. The joke: a party-hat bird up in the sky drops its popcorn in shock, and a tiny snail on the hill below waves a green GO flag for its old rival. Drawn 100% procedurally by `main.py` (own rasterizer + PNG encoder, Python standard library only, no network, fully deterministic — two runs produce byte-identical output).

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, ~31 KB).
